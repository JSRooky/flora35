# Справка по модулям



Краткие подсказки по работе с панелями приложения.



## feature



**Сведения о точке** — после клика по маркеру. Переключатели у полей включают фильтр по этому свойству. **Сбросить фильтры** — убрать фильтры текущей точки. Кнопки **Радиус** и **Буфер** открывают соответствующие инструменты под панелью точки.

Для точек GBIF без русского названия в строке **Название** показывается кнопка **Найти** — по клику имя ищется в локальном каталоге, GBIF и Wikidata. Найденные названия хранятся отдельно от выгрузки GBIF и сохраняются при обновлении данных.



## areal



**Радиус** — окружность вокруг точки (или всех видимых точек) заданного радиуса. **Установить радиус** / **Ко всем видимым маркерам**, радиус — слайдером. Нужна выбранная точка.



## polygon



**Полигон** — ареал по всем точкам выбранного вида (латинское название). Экспериментальная функция. Без выделенной точки — подсказка «Выделите любую точку». **Построить** — оболочка; иконка режима — все точки. **Добавить полигон** — ареал другого вида. При двух и более ареалах — блок **Пересечение ареалов**: выберите два вида, **Вычислить** покажет зону пересечения на карте, площадь и точки внутри; **Сброс** уберёт overlay пересечения.



## buffer



**Буфер** — три концентрические зоны (красная → жёлтая → зелёная) вокруг точки. **Построить буфер**, затем слайдеры. **Сброс** — убрать с карты. Нужна выбранная точка.



## area



**Область** — контур на карте: **Произвольная**, **Прямоугольник** или **Полигон** (кнопка включает рисование). Список точек внутри. **Сброс** — очистить.



## year



**Год находки** — фильтр по диапазону годов (два ползунка). Блокируется, если год уже отфильтрован в «Сведения о точке».



## seasonality



**Сезонность** — гистограмма находок по месяцам для вида выбранной точки (по латинскому названию). Учитываются точки текущей выборки карты (фильтры). Точки без месяца (часто локальные или старые снимки внешних данных) считаются отдельно. **Широтный анализ** — окно по широте (вертикальный ползунок) и долготе (горизонтальный); гистограмма пересчитывается для точек внутри окна. Для полных данных GBIF/iNat перезагрузите внешние источники.



## areal-dynamics



**Динамика ареала** — надстройка над **Таймлайном**. Включите **Таймлайн**, затем переключатель **Динамика ареала** над слайдером. Выделите точку вида на карте — появятся цветные слои расширения ареала по годам. Иконка **пятиугольника / звезды** переключает между выпуклой оболочкой и режимом **«Все точки»** (нужно не менее трёх точек вида). **Скрыть остальные** — оставить на карте только точки выбранного вида. Слайдер показывает накопленные находки и срезы до выбранного года; клик по году в легенде перемещает слайдер. **Сброс** убирает overlay.



## status



**Статус МСОП** — фильтр по категориям Красной книги / IUCN. Отметьте один или несколько статусов.



## regnum



**Царство** — фильтр точек на карте по царству. Кнопка внизу слева рядом со **Слои внешних источников**. Отметьте одно или несколько; без отметок показываются все точки. Действует на локальный, внешний и слитый слои.



## map



**Группы точек** — кластеризация, кластеры по царству, кластеры-диаграммы, плотные группы (кнопка **Обработка** открывает отдельную панель и скрывает остальные), видимость маркеров, тепловая карта. Угловая кнопка фильтра на карте **сбрасывает** все активные фильтры, включая режим плотных групп.



## dense



**Обработка плотных групп** — панель из «Группы точек». На карте только группы с полностью одинаковыми координатами; порог числа точек задаётся ползунком (по умолчанию ≥10). Остальные точки скрыты. **Список** — перечень групп и число точек в каждой (клик раскрывает группу и зумирует к её точкам). Клик по оранжевому маркеру тоже раскрывает группу. Угловая кнопка фильтра сбрасывает и этот режим.



## oopt



**ООПТ** — границы особо охраняемых природных территорий и заповедников. Включите нужные слои переключателями. **Маркеры** — показ или скрытие всех точек находок на карте. Клик по полигону на карте открывает панель **Сведения об ООПТ**.



## oopt-feature



**Сведения об ООПТ** — свойства выбранной территории, площадь и сводка **внутри точек / видов**. Иконка списка открывает перечень видов (дерево по царствам и семействам). **Только эти** — показать или скрыть только точки внутри выбранного полигона, не включая остальные маркеры. Сброс всех фильтров карты — угловая кнопка фильтра.



## submit



**Ввод данных о находке** — добавление находок в Firestore. Клик по карте → форма → **Сохранить**.



## data-sources



**Источники данных** — локальная копия внешних находок. Кнопка **Загрузить регионы** открывает отдельное плавающее окно с таблицей субъектов РФ: число точек GBIF по царствам, оценка объёма, выбор царства и кнопки **Загрузить** / **Обновить**.



## external-processing



**Обработка внешних данных** — клиентские фильтры уже загруженных слоёв GBIF и iNaturalist: источник (GBIF / iNaturalist / оба), царство, семейство, поиск по латыни. Фильтры не меняют сохранённый снимок — только отображение на карте и участие в инструментах.



## data-work



**Работа с данными** — каталог инструментов. **Близкие точки**: пары GBIF ↔ iNaturalist в радиусе; **Объединить** / **Слить эту пару** создаёт точку на слое «Слитые точки». **Без атрибуции**: клик по строке открывает окно заполнения пустых полей (сохранение в Firestore `point_attributions`). Слой слитых точек — в **Группы точек**.



## gbif



**Данные GBIF** — загрузка находок из GBIF на отдельный слой карты (цвета маркеров — как у локальных точек, по царству). Открывается выбором **GBIF** в меню «Точки». Выберите регион и нажмите **Загрузить** — точки по региону сохранятся локально и добавятся к уже загруженным (совпадения по GBIF ID обновятся). Фильтры по царству, семейству и латыни — в панели **Обработка данных GBIF**.



## gbif-processing



**Обработка данных GBIF** — клиентские фильтры уже загруженного слоя: царство, семейство, поиск по латыни. Открывается кнопкой **Обработка данных GBIF** в панели загрузки. Если развёрнута обработка, панель **Данные GBIF** сворачивается (и наоборот). Фильтры не меняют сохранённый снимок — только отображение на карте и участие в инструментах.



## redbook



**Поиск редких видов** — загрузите список латинских названий (TXT/JSON), при необходимости со статусом (`EN`, `VU`…; без статуса — `None`). **Найти в GBIF / iNat** собирает совпадения среди уже загруженных внешних точек в отдельный слой **Красная книга**. Список и совпадения пока хранятся локально (JSON / localStorage).
