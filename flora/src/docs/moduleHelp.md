# Справка по модулям

Краткие подсказки по работе с панелями приложения.

## feature

**Сведения о точке** открываются после клика по маркеру на карте.

Здесь показаны свойства выбранной находки: название вида, координаты, год находки и другие поля. Рядом с каждым свойством можно включить **фильтр** — на карте останутся только точки с таким же значением.

Кнопка **Ареал** открывает панель ареала под этой панелью, не закрывая сведения о точке. Тот же модуль можно открыть отдельно из верхнего меню — тогда панель точки закроется.

Кнопка **Сбросить фильтры** убирает фильтры, связанные с текущей точкой. Статус вида (МСОП) фильтруется отдельно в модуле «Статус МСОП».

## areal

Модуль **Ареал** строит зону поиска вокруг точки или вокруг всех видимых маркеров.

- **Установить ареал** — круг заданного радиуса вокруг выбранной точки (доступно, если точка не скрыта внутри кластера).
- **Ко всем видимым маркерам** — такие же круги вокруг каждой отдельно отображаемой точки с учётом активных фильтров.
- **Радиус** задаётся слайдером в километрах с шагом в 0,1 км.

В списке ниже показываются другие точки, попавшие в ареал выбранной точки. Клик по названию в списке перемещает карту к этой точке.

## polygon

Модуль **Полигон** (экспериментальный) строит область по всем точкам **того же вида**, что и выбранная находка. Вид определяется по латинскому названию.

Полигон строится как выпуклая оболочка (Turf.js). Для одной или двух точек вместо оболочки рисуется небольшая буферная область.

Нажмите **Построить**, чтобы построить полигон по точкам выбранного вида. **Сбросить** убирает полигон с карты. При выборе другой точки уже построенный полигон сохраняется, пока вы не нажмёте **Построить** или **Сбросить**.

## year

**Год находки** позволяет ограничить набор точек по диапазону лет.

Включите переключатель фильтра и задайте минимальный и максимальный год с помощью двух ползунков. На карте останутся только точки, год находки которых попадает в выбранный интервал.

Если для точки уже включён фильтр по полю «found_year» в модуле «Сведения о точке», фильтр по году здесь временно блокируется.

## status

**Статус МСОП** — фильтр по категориям Красной книги / IUCN (CR, EN, VU, LC и др.).

Отметьте один или несколько статусов — на карте останутся только соответствующие точки. Снятие всех галочек показывает весь набор данных (с учётом других активных фильтров).

## map

**Операции с картой** управляют отображением точек и кластеров.

- **Группировать точки** — включает или отключает кластеризацию близких маркеров.
- **Кластеризовать по царству** — отдельные кластеры для растений и животных (работает только при включённой кластеризации).
- **Показывать маркеры** — скрывает или показывает точки на карте.
- **Тепловая карта** — вместо маркеров отображает плотность находок; учитывает текущие фильтры.
