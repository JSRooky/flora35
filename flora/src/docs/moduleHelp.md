# Справка по модулям

Краткие подсказки по работе с панелями приложения.

## feature

**Сведения о точке** открываются после клика по маркеру на карте.

Панель содержит основные характеристики находки: название вида (русское и латынь), год находки (если есть), другие поля. Переключатель рядом с характеристикой включает фильтр по этому свойству и отображает на карте точки с аналогичным значением.

Кнопка **Сбросить фильтры** убирает фильтры, связанные с текущей точкой. Статус вида (МСОП) фильтруется отдельно в модуле «Статус МСОП».

Кнопка **Ареал** открывает инструмент построения возможной зоны распространения вида (максимум - 15 км) для оценки возможных мест нахождения вида.

Кнопка **Буфер** открывает инструмент построения буферных зон для оценки вероятности нахождения вида в заданных радиусах от места находки.

Инструменты "Буфер" и "Ареал" аналогичны тем, которые вызываются из главного меню.

## areal

Инструмент **Ареал** создает вокруг выбранной точки (или всех видимых точек) окружности заданного радиуса, в котором вероятны дальнейшие находки.

Это не точная оценка, а область вероятного распространения, которую устанавливаете вы.

- **Установить ареал** — круг заданного радиуса вокруг выбранной точки (если точка находится в кластере, ареал для нее не строится).
- **Ко всем видимым маркерам** — выполняется построение для всех отображаемых точек.
- **Радиус** задаётся слайдером в километрах с шагом в 0,1 км.

Если в построенную окружность попадают другие точки, их список выводится ниже. Кликом по нужному пункту списка центрирует карту на соответствующей точке.

## polygon

Модуль **Полигон** строит область по всем точкам **того же вида**, что и выбранная находка. Вид определяется по латинскому названию.

Это **экспериментальная функция**, она может работать некорректно. Пожалуйста, проверяйте результат.

Полигон строится как выпуклая оболочка. Для одной или двух точек вместо оболочки рисуется небольшая буферная область.

Нажмите **Построить**, чтобы построить ареал по точкам выбранного вида. Кнопка **Все точки** (при трёх и более точках вида) строит полигон через все точки вместо выпуклой оболочки.

Можно построить **несколько ареалов** для разных видов: нажмите **Добавить полигон** и выберите точку другого вида на карте. На один вид — один ареал; повторное построение для того же вида обновляет его полигон. Каждый ареал в списке можно временно **скрыть** с карты или **сбросить** отдельно; **Сбросить всё** убирает все ареалы.

Список «В полигоне: N видов» показывается только при одном построенном ареале. При нескольких ареалах этот список скрыт.

При выборе другой точки уже построенные ареалы сохраняются, пока вы не сбросите их явно.

## buffer

Модуль **Буфер** строит вокруг выбранной точки набор из трех концентрических окружностей, диаметр которых находится в созависимости:

- Наименьший диаметр у красной зоны, наибольший - у зеленой.
- Диаметр каждой следующей зоны не может быть меньше диаметра предыдущей.
- Максимальный диаметр зеленой зоны - 15 км.

Инструмент служит для построения зон оценки вероятности новой находки вида. В красной зоне находка наиболее вероятна, в зеленой - наименее.

Чтобы включить инструмент, нажмите кнопку **Построить буфер**. После включения его можно менять слайдерами зон. Кнопка **Сброс** убирает буфер с карты и сбрасывает настройки.

## area

Модуль **Область** позволяет нарисовать на карте произвольный контур и увидеть точки, попавшие внутрь выделения.

- Нажмите **Рисовать**, затем зажмите левую кнопку мыши и обведите нужную область на карте.
- После отпускания кнопки контур замыкается, а в панели появляется список точек с учётом активных фильтров.
- Клик по названию в списке перемещает карту к точке.
- **Сброс** убирает область с карты и очищает список.

## year

**Год находки** позволяет ограничить отображение точек временным диапазоном.

Включите переключатель фильтра и задайте минимальный и максимальный год с помощью двух ползунков. На карте останутся только точки, год находки которых попадает в выбранный интервал.

Если для точки уже включён фильтр по полю «found_year» в модуле **«Сведения о точке»**, фильтр по году здесь временно блокируется. Отключите фильтр по году в панели "Сведения о точке", чтобы разблокировать данный инструмент.

## status

**Статус МСОП** — фильтр по категориям Красной книги / IUCN (CR, EN, VU, LC и др.).

Отметьте один или несколько статусов — на карте останутся только соответствующие точки. Снятие всех галочек показывает весь набор данных (с учётом других активных фильтров).

## map

**Группы точек** управляют отображением точек и кластеров.

- **Группировать точки** — включает или отключает кластеризацию близких маркеров.
- **Кластеризовать по царству** — отдельные кластеры для растений, грибов и животных (работает только при включённой кластеризации; недоступно вместе с кластерами-диаграммами).
- **Кластеры-диаграммы** — показывает состав каждого кластера секторной диаграммой (растения, животные, грибы); при включении отключает группировку по царству.
- **Показывать маркеры** — скрывает или показывает точки на карте.
- **Тепловая карта** — вместо маркеров отображает плотность находок; учитывает текущие фильтры.

## submit

Модуль **Ввод данных о находке** добавляет пользовательские находки в файл `src/locations/userpoints.json` в том же формате `SpeciesCollection`, что и `points.json`. Работает при локальном запуске (`npm start`).

Кликните по карте, чтобы указать координаты находки, заполните поля формы и нажмите **Сохранить**. Новая точка сразу появляется на карте вместе с данными из `points.json`.

**Вид (species)** — общие сведения о таксоне:

- **id** — формируется автоматически из латинского названия.
- **name_ru**, **name_latin**, **regnum**, **status**, **family** — обязательны при первой записи вида.

**Находка (findings)** — сведения о конкретной точке:

- **id** — формируется автоматически (`{id вида}-{номер}`, например `meles-meles-001`).
- **coordinates** — координаты с карты в формате `[долгота, широта]`.
- **found_year**, **found_by** — обязательны; **identified_by** может быть пустым.

Если вид с таким латинским названием уже есть в файле, добавляется только новая находка; поля вида не перезаписываются.
