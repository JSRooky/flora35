# Справка по модулям



Краткие подсказки по работе с панелями приложения.



## feature



**Сведения о точке** — после клика по маркеру. Переключатели у полей включают фильтр по этому свойству. **Сбросить фильтры** — убрать фильтры текущей точки. Кнопки **Ареал** и **Буфер** открывают соответствующие инструменты под панелью точки.



## areal



**Ареал** — окружность вокруг точки (или всех видимых точек) заданного радиуса. **Установить ареал** / **Ко всем видимым маркерам**, радиус — слайдером. Нужна выбранная точка.



## polygon



**Полигон** — ареал по всем точкам выбранного вида (латинское название). Экспериментальная функция. Без выделенной точки — подсказка «Выделите любую точку». **Построить** — оболочка; иконка режима — все точки. **Добавить полигон** — ареал другого вида.



## buffer



**Буфер** — три концентрические зоны (красная → жёлтая → зелёная) вокруг точки. **Построить буфер**, затем слайдеры. **Сброс** — убрать с карты. Нужна выбранная точка.



## area



**Область** — контур на карте: **Произвольная**, **Прямоугольник** или **Полигон** (кнопка включает рисование). Список точек внутри. **Сброс** — очистить.



## year



**Год находки** — фильтр по диапазону годов (два ползунка). Блокируется, если год уже отфильтрован в «Сведения о точке».



## status



**Статус МСОП** — фильтр по категориям Красной книги / IUCN. Отметьте один или несколько статусов.



## map



**Группы точек** — кластеризация, кластеры по царству, кластеры-диаграммы, видимость маркеров, тепловая карта.



## submit



**Ввод данных о находке** — добавление находок в `userpoints.json` при локальном запуске. Клик по карте → форма → **Сохранить**.
