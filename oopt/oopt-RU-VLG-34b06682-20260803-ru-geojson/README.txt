Данные по ООПТ для вашей ГИС      
========================================   

## Общая информация   

Получить свежие данные по ООПТ в удобном формате можно с помощью data.nextgis.com    

Источники:   
   * Информационно-аналитическая система «Особо охраняемые природные территории России» (ИАС «ООПТ РФ») - http://www.oopt.aari.ru     
   * OpenStreetMap (https://osm.org) - открытая база геоданных и сообщество редакторов, поддерживающих её в актуальном состоянии.   


## Содержание   

Каждая выгрузка содержит следующие слои данных:   
   * границы ООПТ из ИАС ООПТ - точки (oopt_pnt)   
   * границы ООПТ из ИАС ООПТ - полигоны (oopt_pol)   
   * границы ООПТ из OpenStreetMap - полигоны (nature_reserve-polygon)   
   * границы охранных зон ООПТ - ИАС "ООПТ России" (полигоны) (oopt_oz_pol)   
   * готовый проект для вашей ГИС (только для форматов QGIS, ArcGIS Pro и ArcMap)   
   * граница заказа (order_boundary.geojson)
